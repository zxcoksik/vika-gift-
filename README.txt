ПОДАРОК ДЛЯ ВИКИ

1. Положи песню рядом с index.html и назови файл heroes.mp3. Без неё сайт работает, но без музыки.
2. Открой script.js. Вверху блок CONFIG: впиши дату, место, время, дресс-код и своё письмо.
   Для кнопки "Добавить в календарь" заполни iso, например "2026-11-14T18:00".
3. Фото для кадров и игры «найди пару»: photo.jpg (первый слайд и карточка) и p1.jpg ... p5.jpg (галерея) лежат рядом с index.html. Подписи к ним, купоны, код сейфа и секрет тоже в CONFIG.
   Карточка героя: в CONFIG есть stats (характеристики) и back (обратная сторона карточки).
4. Список из 100 причин тоже в script.js (строка const R=...), разделитель |.
   Замени общие причины на личные: так подарок сработает сильнее всего.
5. Открой index.html в браузере.

Чтобы отправить ссылкой, загрузи папку на бесплатный хостинг статических сайтов (GitHub Pages, Netlify и похожие).
Микрофон для свечей работает только на https-ссылке или на своём компьютере.
